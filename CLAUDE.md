# MPE Project Page

GitHub Pages site for the paper "Improving Long-Context Retrieval with Multi-Prefix Embedding".

## Structure

- `index.html` — Single-page project site (Bulma CSS, no build step)
- `static/images/` — Figures from the paper (PNG/JPG)
- `mpe.tex` — LaTeX source (workshop preprint, CEUR-ART template)
- `references.bib` — Bibliography

## Deployment

- Hosted via GitHub Pages on the `gh-pages` branch
- Live at: https://farmerswrap.github.io/mpe/
- Push to `gh-pages` to deploy; no CI/build needed

## Paper content

- Authors: Zhenglin Yu, Xueguang Ma (corresponding), Shengyao Zhuang, Zhichao Xu, Luyu Gao, Crystina Zhang, Jimmy Lin
- Venue: LateInteraction'25 Workshop
